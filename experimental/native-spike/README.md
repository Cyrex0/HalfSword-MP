# Native transport spike: not shipped

This is the spike for moving HSMP's game-side transport from files into the game process, to get past
the limits of the file IPC between the Lua mods and the sidecar (see
`docs/development/architecture.md`, "Known architectural limits"). It is **experimental, not part of
the release and not built by the Cargo workspace**.

Two options were built and verified offline:

- **Option F**: a UE4SS C++ mod (`HSMPNative/dlls/main.dll`) linking a Rust core.
- **Option E**: a Lua C module written in Rust (`hsmp_lua.dll`), loaded with `require`.

**Result.** Both options passed an offline harness against a mock UE4SS (UDP loopback echoes in about
10 µs, GC stress across the two Lua copies), with the ABI checked against the shipped `UE4SS.dll`
through its export table, PDB and disassembly. Option F was adopted: its production successor,
`crates/hsmp-native`, then ran in the real game, where UE4SS's `on_lua_start` registered `HSMPNative`
into the HSMP mods' Lua states, the Lua lock was forwarded to UE4SS's own `LuaLock`/`LuaUnlock`, and a
`frame()` call cost about 4 µs (p50) / 6 µs (p99) on the game thread. Option E stays the fallback: it
needs no `CppUserModBase` or vtable coupling, only the Lua struct layout.

## Layout

| Path | What it is |
|---|---|
| `cpp/abi/ue4ss_abi.hpp` | Hand-written view of the UE4SS C++ mod ABI, verified against the shipped `UE4SS.dll` (it does not use UE4SS's Unreal headers) |
| `cpp/abi/UE4SS.def`, `ue4ss_pins.h` | Generated by `tools/ue4ss_pins` from the pinned `UE4SS.dll` and its PDB |
| `cpp/src/` | The C++ mod, the Lua C module glue and the lock bridge |
| `cpp/test/` | Offline harness against a mock UE4SS |
| `crates/hsmp_core_stub` | Rust stand-in for the transport core: UDP thread and lock-free SPSC queues, C ABI |
| `crates/hsmp_lua_e` | Option E as a Rust staticlib |
| `tools/ue4ss_pins` | Pins the build to one exact `UE4SS.dll` |
| `lua/HSMPNativeProbe` | The in-game probe mod |

All of this is HSMP's own code (MIT OR Apache-2.0). It links Lua 5.4.7 from an RE-UE4SS checkout,
which is not part of this repository.

## Build (Windows, MSVC)

Needs CMake 3.22+, Visual Studio 2022 (C++), Rust, and an RE-UE4SS checkout at the pinned commit
`e3ba1016` (default location `third_party/RE-UE4SS`, which is git-ignored):

```powershell
cmake -S experimental/native-spike -B experimental/native-spike/build -G "Visual Studio 17 2022" -A x64 -DUE4SS_SRC=<path to RE-UE4SS>
cmake --build experimental/native-spike/build --config RelWithDebInfo
ctest --test-dir experimental/native-spike/build -C RelWithDebInfo --output-on-failure
```
