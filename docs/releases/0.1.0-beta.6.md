# HalfSword-MP 0.1.0-beta.6

This beta updates the existing PvP multiplayer mod for Half Sword. Native headless
hosting and co-op remain on the development branch and are not part of this package.

## Changes

- Adds the lobby game-mode screen, team elimination, king of the hill, weapon
  roulette, brawl and timed deathmatch, plus mode and team information in the HUD.
- Adds server-provided Lua mods with explicit consent before download and execution.
  Only accept mods from a server you trust: accepted mods run with access to your PC.
- Improves protected spawn placement, current-life pose handling, empty-hand
  loadouts and stuck-blade continuation ordering.
- Preserves more native armour and weapon passport information while adding bounded
  diagnostics for unresolved physical and damage differences.
- Improves launcher startup reporting and graphics initialization recovery.
- Keeps actual server command replies during menu shutdown, including readiness
  replies that arrive while leaving a session.

## Known issues

- A fighter can still spawn out of position, fall, take longer to settle or remain
  waiting for input release. These spawn issues are accepted limitations of this beta.
- Remote arms and wrists can twist or drift, and weapons or feet can lag or overshoot.
  Heavy frame cost can make the visible fight less accurate.
- Native body construction, dismemberment, clothing and armour parity remain
  unfinished. Partial cuts and detached components are not fully replicated.
  This release does not establish complete single-player physics or damage parity.
- The native two-round Yard check passed its functional combat, spawn and world
  gates, but foot slide measured 8.04 and 6.06 cm against the existing 5 cm bound.
  Full G2, twice-green native scenarios and all-gear parity are not established.

## Compatibility and installation

Use matching beta.6 clients and servers. This release uses protocol 12 and is
incompatible with earlier clients, including beta.5.

The supported game is Half Sword Steam build 24185754 (UE 5.4.4), with the pinned
RE-UE4SS experimental build e3ba1016. Install the signed package through the launcher;
see [installation](../players/install.md). Beta users must allow prerelease updates.

The release assets are hsmp-0.1.0-beta.6.zip and hsmp-0.1.0-beta.6.zip.sha256 under
the prerelease tag v0.1.0-beta.6. Packages have a signed manifest and per-file hashes.

## Validation scope

The release candidate passed full local G0 with the game dump (70 Lua suites,
1,284 Rust tests and clippy), nine native C++ tests, and the complete real UDP/HTTP
end-to-end suite (195 passed, zero failed). The local Cloudflare Worker check was
skipped because the installed Node version is below its minimum; the public
master health and server-list endpoints were checked separately.

Real two-client map-change/menu-shutdown and reconnect checks passed, including
an eight-second blackout that restored the same seat and score. These checks
establish the recorded scenarios only; the known native parity gaps above remain.
